# 🌌 Mundo Invertido

Projeto de desenvolvimento web inspirado no universo de **Stranger Things**, criado durante meus estudos de Front-End na **DIO**.

A proposta foi desenvolver uma experiência visual temática, explorando identidade visual, composição, navegação, efeitos e interação para criar uma interface inspirada no conceito do Mundo Invertido.

## 📌 Sobre o projeto

O projeto apresenta uma landing page temática inspirada na atmosfera de *Stranger Things*, utilizando elementos visuais e interativos para criar uma experiência imersiva.

Durante o desenvolvimento, foram trabalhados conceitos de estruturação de páginas, estilização, organização visual e interação com o usuário.

## 📱 Responsividade

A interface foi desenvolvida considerando diferentes tamanhos de tela, buscando proporcionar uma experiência consistente em dispositivos desktop e mobile.

## 📚 Desenvolvimento

Projeto desenvolvido durante minha formação em **Front-End pela DIO**, como prática de desenvolvimento de interfaces e aplicação dos conhecimentos adquiridos em HTML, CSS e JavaScript.

Além da proposta original do projeto, foram realizadas adaptações e personalizações como parte do processo de aprendizado e desenvolvimento.
